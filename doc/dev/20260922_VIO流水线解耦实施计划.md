# VIO 流水线解耦实施计划

依据：用户确认的最终方案及 Basalt `a0c4fdfc103778510523e89a99242af09f23d4fa`。

## 确认的边界

必须提供 Basalt run 和完整相机/IMU 交付。直接引用其已准备的数据目录，原样导入 GT 和对比轨迹；不重新同步、不搜索时间偏移、不重新转换 GT。不校验物理 IMU 坐标系或 marker–IMU 标定一致性。只支持新格式 OKVIS run，不迁移历史结果。

## 实施步骤

1. 本地化标定读取、位姿 IO、GT 插值和 evo 扩展统计，保存原提交、哈希及许可证。
2. 建立旧平铺/v5 Basalt 数据适配器，检查数据身份、阶段、文件、时间、尺寸和 mask；只引用数据，禁止外部代码依赖。
3. 使用本地 theta 多项式与 OKVIS 实现检查八参数直接映射、有效域和往返误差。
4. 重构阶段入口、格式版本、目录布局、冻结输入复用和资源/覆盖记录；统一全段与截段评测。
5. 加入离线 HTML 报告及独立生成入口，更新使用说明。
6. 在内核禁止访问 Basalt 代码/构建目录的环境下验证短段和全段；对固定历史轨迹验证数值一致性。

## 验收原则

以输入和参考数据不变、无外部代码调用、时间精度与评测口径一致作为工程验收。VIO 输出存在运行差异，不把轨迹逐字节一致或精度改善作为本次重构要求。缺失、失败与未验证项明确记录。
