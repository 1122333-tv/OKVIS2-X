# 基于稳定复现模式重新排查 VIO 漂移

## 目标与冻结条件

从 21a96cb 创建 fix/vio-drift-reproducible。保留 DBoW2、opengv 已有脏状态。
当前三次稳定基线全程 APE RMSE 142.64 m；约 36.067 s 首次大重投影误差。
目标是解释并修复 36 s 退化及其到 44–55、63–66 s 的传播，并保持同机器、同二进制、同输入的逐帧精确复现。
四相机纯 VIO；固定种子 12345；检测串行、匹配/实时求解线程 1；enforce_realtime=false；回环/final BA 关闭。不重新标定、不修改 Basalt、不推送合并。

## 实施顺序

1. 冻结原输入、配置、GT、二进制、动态依赖、源码/子模块差异及父基线。所有实验独立目录、从原始起点顺序完整运行。
2. 选择性迁移历史默认关闭诊断，不带 Huber/恢复策略。先验证开关前后输出字节一致，若不一致先查诊断副作用。
3. 关联初始化至 34 s、34–38 s、43–46 s、60–70 s 的 IMU/预测姿态、匹配/RANSAC、优化及剔除前后约束、各相机贡献、速度/bias、求解状态。用 15–35 s 固定 SE(3) 对齐补充全程结果。
4. 单变量修正匹配统计：最终匹配只计一次、有效数量加权、显式处理零匹配。分别报告代码正确性与轨迹收益。
5. 独立输入副本替换历史标出的少量异常陀螺样本，作为因果隔离，绝不作为最终修复。
6. 若确认 IMU 预测导致有效视觉约束被提前剔除，验证只依据在线一致性及几何内点的条件视觉恢复，不硬编码时间、不使用 GT。
7. 仅在残差证据支持时独立验证 IMU 鲁棒损失，覆盖创建、复制、合并。单因素有效后才组合，并做撤销对照。
8. 仅在迭代耗尽或无效投影实际发生时测试对应修复，不做无目标搜索、不换种子挑结果。

## 验证与交付

筛选各完整运行一次；最终候选/撤销各三次。要求 2402 输出、2401 共同评估、固定 GT 帧对及三次逐帧状态/字节一致。
报告全程 SE(3) APE、0.1/0.5/1 m 与固定时间平移/旋转 RPE、耗时；增加 34–38 s 窗口。历史 0–44 s 不视为触发前正常区间。
异常窗口 RMSE/p95/峰值及 APE 至少下降 50%，其他窗口不明显退化。由于基线发散，相对门槛通过仅代表改善；根因结论同时要求机制证据和绝对误差。
实际修改增加针对性测试，完成 Release 构建及相关现有测试。同标定独立录制回归。
交付可复现命令、机制时间线、实验表、撤销证据、可打开图像及嵌入图片报告。实现与文档分别提交。
