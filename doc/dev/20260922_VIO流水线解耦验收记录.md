# VIO 流水线解耦验收记录

日期：2026-09-22。新接口与目录版本已实现，工程验证通过；本次未调整 VIO 算法参数或输入 IMU。

## 实现结果

- 必填 Basalt run 与标定交付；直接引用已准备的数据目录，不重新同步或复制数据集。
- 原样导入 GT 与 Basalt VIO，保留有效段和来源哈希，不应用第二次时间/外参变换。
- 不校验物理 IMU 坐标系及 marker–IMU 标定一致性。
- 脚本依赖已本地化，许可证及上游 `a0c4fdf` 原文件哈希保存在 `scripts/vendor/`。
- 相机检查改为本地多项式与 OKVIS 有效域/往返检查，没有 Basalt 相机头文件依赖。
- 新格式输入复用、全段/截段评测、evo GUI、重复运行汇总及离线 HTML 报告已接通。历史 OKVIS 格式明确拒绝。

## 验证证据

23 项 Python 测试、2 个 C++ 回归程序通过。覆盖新旧 Basalt 布局、导入不修改源文件、数据身份、缺失/冲突产物、GT 有效段、时间偏移冲突、mask 覆盖、无效轨迹、旧格式拒绝、配置类型差异、失败 run 记录、旧参数拒绝及报告转义/缺失信息。

固定历史轨迹重评的 native/common × OKVIS/Basalt × APE/三项 RPE，共 16 组完整统计字典与原结果完全相等，共同时间戳也一致。该检查直接向评测器传入轨迹文件，不构成历史 OKVIS run 接口兼容。

Basalt 真实 v5 run 的适配器检查通过，包括 Layout0921 `run_20260922T104634_12bfae`；旧平铺布局由独立测试夹具覆盖。

## 隔离运行

命名空间隔离在本机不可用，改用内核 Landlock：允许读取 Basalt `results/`，拒绝其余仓库目录。验证脚本在执行前实际尝试读取 Basalt Python 脚本、时间对齐程序和 KB4 头文件，均得到 PermissionError。限制由子进程继承，不改动源目录权限。

- 300 帧短段：VIO 输出 300/300，重评及报告完成。
- 全段：`run_20260922T170811_isolated_full_f00312` 输出 2402/2402，无缺帧，结束缺口 0；共同 GT 时间戳 2401。
- VIO 墙钟约 352.30 s；OKVIS 位置 APE RMSE 0.253114 m，Basalt 0.029467 m。精度改善不是本次验收目标，缓存/系统负载未隔离。
- 四张 mask 中共 3,377,949 个像素通过本地模型检查。
- 导入参考文件与来源逐字节一致，五份输入索引哈希保持一致。图像进行了存在性和尺寸检查，没有重算全部图像内容校验和。
- 0–44 s 截段重评成功；重复运行汇总工具通过单 run 冒烟验证，不把它作为多次重复稳定性实验。

## GUI 与报告边界

evo 的四项指标对比与轨迹 Qt 窗口采用离屏 Qt 自动关闭方式验证；用户桌面上的交互窗口未进行人工操作验收。

报告通过静态检查：图片全部内嵌，无外部 CSS/JS/字体。浏览器 localhost 检查确认页面加载、配置搜索和图片放大可用；未验证真实断网 file URL 浏览和打印分页。报告页面和 JSON 的指标来自既有统计，不重新计算。

开发过程中保留了失败 run：首次相机检查因图像边界约 1e-11 px 的舍入被误判，修复为带 1e-5 px 往返容差的边界处理；第一次隔离报告被测试环境的跨目录 rename 限制阻止，补充 Landlock REFER 权限后通过。两项均未更改模型参数、mask 或算法行为。
